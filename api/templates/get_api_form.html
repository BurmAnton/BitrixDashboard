Документация REST API получение объекта

                    


                    
                    

                        
Эндпоинты

                        
    
                        
  • GET /api/get/organization/?inn=<ИНН> – получение организации
    • 
                        
  • GET /api/get/program/?pk=<ID> – получение программы
    • 
                        


                        
Назначение

                        
Получение детальной информации об организации по ИНН или об образовательной программе по первичному ключу (ID).


                        
Аутентификация

                        
Требуется токен в заголовке Authorization.

                        Формат: Authorization: Token <ваш_токен>

                        
Токен можно получить в админ-панели Django (раздел «Токены»). Доступ только у суперпользователей.


                        
Параметры запроса

                        

                        
                        

                            Эндпоинт
                            Параметр
                            Тип
                            Описание
                        

                        
                        
                        

                            /organization/
                            inn
                            string
                            ИНН организации (10 или 12 цифр)
                        

                        

                            /program/
                            pk
                            integer
                            Первичный ключ (ID) программы
                        

                        
                        



Примеры запросов



cURL

Организация по ИНН:

curl -X GET "https://bitrix24.tuna-edu.ru/api/get/organization/?inn=7707083893" \
-H "Authorization: Token 4a8389aa7f015d3a68e44e3f4bae94d63c7ac097"

Программа по PK:

curl -X GET "https://bitrix24.tuna-edu.ru/api/get/program/?pk=42" \
-H "Authorization: Token 4a8389aa7f015d3a68e44e3f4bae94d63c7ac097"



JavaScript (fetch)

Организация:

fetch('/api/get/organization/?inn=7707083893', {
headers: { 'Authorization': 'Token 4a8389aa7f015d3a68e44e3f4bae94d63c7ac097' }
})
.then(response => response.json())
.then(data => console.log(data));

Программа:

fetch('/api/get/program/?pk=42', {
headers: { 'Authorization': 'Token 4a8389aa7f015d3a68e44e3f4bae94d63c7ac097' }
})
.then(response => response.json())
.then(data => console.log(data));



Python (requests)

Организация:

import requests
headers = {'Authorization': 'Token 4a8389aa7f015d3a68e44e3f4bae94d63c7ac097'}
params = {'inn': '7707083893'}
response = requests.get('https://bitrix24.tuna-edu.ru/api/get/organization/', headers=headers, params=params)
print(response.json())

Программа:

import requests
headers = {'Authorization': 'Token 4a8389aa7f015d3a68e44e3f4bae94d63c7ac097'}
params = {'pk': 42}
response = requests.get('https://bitrix24.tuna-edu.ru/api/get/program/', headers=headers, params=params)
print(response.json())

Возможные ошибки






    Код
    Эндпоинт
    Описание
    Пример ответа






    400
    /organization/
    Не передан ИНН
    {"error": "ИНН обязателен", "usage": "/api/get/organization/?inn=<ИНН>"}




    400
    /program/
    Не передан pk
    {"error": "Ключ обязателен", "usage": "/api/get/program/?pk=<pk>"}




    401
    оба
    Отсутствует или неверный токен
    {"detail": "Authentication credentials were not provided."}




    403
    оба
    Недостаточно прав
    {"detail": "You do not have permission to perform this action."}




    404
    /organization/
    Организация не найдена
    {"error": "Организация с ИНН 1234567890 не найдена"}




    404
    /program/
    Программа не найдена
    {"error": "Программа по ключу 999 не найдена"}







Примечания


    

  • Для организации: ИНН должен быть строкой, содержащей только цифры. Поле projects может быть пустым массивом. fed_district вычисляется автоматически.
    • 

  • Для программы: PK – это числовой идентификатор (первичный ключ) записи в таблице EducationProgram. Поле sections содержит вложенные разделы и темы. Если разделов нет, возвращается пустой массив.
    • 

  • Оба эндпоинта требуют аутентификации через токен (заголовок Authorization: Token <ваш_токен>).
