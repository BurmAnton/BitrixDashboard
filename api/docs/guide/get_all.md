## Введение

Добро пожаловать в документацию REST API для получения справочных данных системы. API предоставляет доступ к федеральным округам, регионам и типам организаций.

**Особенности:** все эндпоинты требуют аутентификации по токену. Данные возвращаются в формате JSON.

## 1. Аутентификация

Для доступа к API требуется токен.

1. В админ-панели Django перейдите в раздел «Токены».
2. Создайте новый токен для нужного пользователя.
3. Сохраните токен для будущего использования.

## 2. Эндпоинты

### 2.1 Федеральные округа с регионами

| | |
|---|---|
| **Эндпоинт** | `/api/get_all/fed_district/` |
| **Метод** | GET |
| **Аутентификация** | Требуется (токен в заголовке Authorization) |
| **Описание** | Список федеральных округов с вложенными регионами |

### 2.2 Регионы

| | |
|---|---|
| **Эндпоинт** | `/api/get_all/region/` |
| **Метод** | GET |
| **Описание** | Список всех регионов |

### 2.3 Типы организаций

| | |
|---|---|
| **Эндпоинт** | `/api/get_all/organization_type/` |
| **Метод** | GET |
| **Описание** | Список типов организаций |

### 2.4 Сферы деятельности

| | |
|---|---|
| **Эндпоинт** | `/api/get_all/prof_activity/` |
| **Метод** | GET |
| **Описание** | Список сфер деятельности |

### 2.5 Формат запроса

**Заголовки:**

| Заголовок | Значение | Описание |
|-----------|----------|----------|
| `Authorization` | `Token YOUR_TOKEN` | Токен аутентификации |
| `Accept` | `application/json` | Формат ответа (рекомендуется) |

### 2.6 Примеры

**JavaScript (Fetch) — федеральные округа**

```javascript
fetch('https://bitrix24.tuna-edu.ru/api/get_all/fed_district/', {
    method: 'GET',
    headers: {
        'Authorization': 'Token ваш_токен_здесь',
        'Accept': 'application/json'
    }
})
.then(response => response.json())
.then(data => console.log(data))
.catch(error => console.error('Ошибка:', error));
```

**cURL — регионы**

```bash
curl -X GET 'https://bitrix24.tuna-edu.ru/api/get_all/region/' \
  -H 'Authorization: Token ваш_токен_здесь' \
  -H 'Accept: application/json'
```

**Python — типы организаций**

```python
import requests
headers = {
    'Authorization': 'Token ваш_токен_здесь',
    'Accept': 'application/json'
}
response = requests.get('https://bitrix24.tuna-edu.ru/api/get_all/organization_type/', headers=headers)
data = response.json()
print(data)
```

## 3. Формат ответа

### 3.1 Успешный ответ (HTTP 200 OK)

Структура зависит от эндпоинта.

### 3.2 Федеральные округа с регионами

```json
[
    {
        "name": "Центральный федеральный округ",
        "region": [
            {"name": "Москва"},
            {"name": "Московская область"},
            {"name": "Белгородская область"}
        ]
    },
    {
        "name": "Северо-Западный федеральный округ",
        "region": [
            {"name": "Санкт-Петербург"},
            {"name": "Ленинградская область"},
            {"name": "Республика Карелия"}
        ]
    }
]
```

### 3.3 Регионы

```json
[
    {"name": "Москва"},
    {"name": "Московская область"},
    {"name": "Санкт-Петербург"},
    {"name": "Ленинградская область"},
    {"name": "Республика Татарстан"}
]
```

### 3.4 Типы организаций

```json
[
    {"name": "Государственное учреждение"},
    {"name": "Частная компания"},
    {"name": "Некоммерческая организация"},
    {"name": "Образовательное учреждение"}
]
```

### 3.5 Структура данных

| Поле | Тип | Описание | Эндпоинт |
|------|-----|----------|----------|
| `name` | String | Название федерального округа | `/fed_district/` |
| `region` | Array | Регионы в округе (объекты с полем `name`) | `/fed_district/` |
| `name` | String | Название региона | `/region/` |
| `name` | String | Название типа организации | `/organization_type/` |

## 4. Коды ответов и ошибки

### 4.1 Успешные коды

| Код | Описание |
|-----|----------|
| `200` | OK — запрос выполнен успешно |

### 4.2 Коды ошибок

| Код | Описание | Решение |
|-----|----------|---------|
| `400` | Bad Request | Проверьте синтаксис URL |
| `401` | Unauthorized | Убедитесь, что передали корректный токен |
| `403` | Forbidden | Токен не имеет прав на доступ к API |
| `404` | Not Found | Проверьте URL эндпоинта |
| `500` | Internal Server Error | Попробуйте позже или обратитесь к администратору |

### 4.3 Пример ошибки 401

```json
{
    "detail": "Authentication credentials were not provided."
}
```

**Решение:** добавьте заголовок `Authorization` с вашим токеном.
